# Open Source Release Notes

This repository contains local research artifacts and live-test traces that are not part of the public framework.

Publish only the sanitized release bundle generated by:

```bash
python scripts/build_open_source_release.py
```

The generated bundle is:

```text
dist/forty-two-auto-open-source/
```

## Include

- `forty_two_auto/`
- `examples/`
- `README.md`
- `requirements.txt`
- `.env.example`
- release `.gitignore`

## Exclude

- `.env`
- project-local agent memory and research folders
- `data/`
- `logs/`
- `reports/`
- legacy private dashboards
- local paper collectors and historical scripts
- private strategy notes
- tx hashes, private wallet addresses, screenshots, or local database files

## Execution Modes

The public framework has four levels:

1. `scan/read-only`: market discovery and classification.
2. `paper`: local simulated fills.
3. `dry-run/plan`: quotes, risk preview, and unsigned order plans.
4. `direct_contract`: BNB Chain direct contract adapter with either per-run explicit confirmation or the unattended live env gate.

Signal/radar and hosted-wallet/browser workflows are not included in the public release. REST execution is intentionally not enabled unless 42 publishes or verifies a supported execution API.
